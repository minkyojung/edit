Octave's cold start is now **3× faster**. We rewrote the workspace loader to
defer non-critical indexing until after first paint, and moved file scanning
off the main thread.

On a typical project (10k files, M-series Mac), cold start dropped from
**~2.6s to ~0.8s**.

No action needed — the change is live for everyone.
