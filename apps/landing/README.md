# Octave Page

Octave 프로젝트를 위한 웹 페이지입니다.

## 시작하기

이 프로젝트를 로컬에서 실행하려면:

1. 파일을 열어 브라우저에서 확인하거나
2. 로컬 서버를 실행하세요

```bash
# Python 3를 사용하는 경우
python -m http.server 8000

# Node.js를 사용하는 경우
npx serve
```

그 후 브라우저에서 `http://localhost:8000`을 열어주세요.

## 프로젝트 구조

```
octave-page/
├── index.html      # 메인 HTML 파일
├── styles.css      # 스타일시트
├── script.js       # JavaScript 파일
└── README.md       # 프로젝트 설명서
```
