# CM 프로토타입 — Obsidian / CM6 기준 갭 (쉬운 정리)

> 기준 축: **Obsidian Live Preview + CodeMirror 6 공식 모듈**. "그쪽엔 되는데
> 우리 CM 프로토타입(`apps/writer-tauri/src/prototypes/`)엔 빠졌거나 부실한 것."
> 자매 문서 [`codemirror-migration-gap-checklist.md`](./codemirror-migration-gap-checklist.md)는
> 다른 축(=Milkdown에 있는데 CM에 없는 것)이라 상호보완. 실측 기준 2026-06-06.

> 각 항목 2줄: **무엇인지 / 왜 문제인지.**

## A. 성능·구조 🔴

**A-1. 뷰포트 윈도잉 없음**
지금은 키 한 번 칠 때마다 문서 전체를 다시 계산함 (화면에 보이는 부분만 하면 되는데).
→ 짧은 글은 괜찮지만 긴 글에서 타이핑이 버벅일 수 있음. (`livePreview.ts:286`, 전체 doc 스캔)

**A-2. 조합 중 데코 위치 보정 안 함**
한글 조합하는 동안 꾸밈(볼드 등) 위치를 안 따라가서 살짝 어긋날 수 있음.
→ 지금 증상은 없지만 잠재적 미세 버그. (`.map(tr.changes)` 미사용)

## B. 편집 손맛 🟡

**B-1. 괄호·기호 자동 닫기 없음**
`(` 치면 `)`가 자동으로 안 생김. `[[`도 마찬가지.
→ Obsidian/노션은 다 되는 기본 입력 편의 없음. (CM: `closeBrackets()`)

**B-2. 선택 후 기호로 감싸기 없음**
글자 선택하고 `*` 눌러도 안 감싸짐 (Cmd+B 같은 단축키만 됨).
→ 마우스로 선택해서 빠르게 강조하는 흐름이 빠짐.

**B-3. URL 붙여넣기 → 자동 링크 없음**
글자 선택하고 링크 붙여넣어도 링크로 안 묶임.
→ 링크 다는 게 한 단계 더 번거로움.

**B-4. 입력 시 자동 들여쓰기 없음**
줄바꿈할 때 들여쓰기가 자동으로 안 맞춰짐.
→ 코드·리스트에서 정렬을 손으로 해야 함. (CM: `indentOnInput()`)

**B-5. 번호 리스트 자동 재정렬 없음**
1·2·3 리스트 중간을 들여쓰거나 지워도 번호가 안 고쳐짐.
→ 번호가 어긋난 채 남음.

**B-6. Tab 리스트 들여쓰기 인식 약함**
Tab이 리스트 구조를 제대로 인식해서 들여쓰지 못함(그냥 공백 취급).
→ 중첩 리스트 만들기가 매끄럽지 않음.

## C. Obsidian 구문 렌더 🟡

**C-1. 콜아웃** `> [!note]`
경고/정보 박스가 그냥 평범한 인용문으로만 보임.
→ Obsidian의 대표 기능인데 미지원.

**C-2. 임베드** `![[노트]]` / `![[이미지]]`
다른 노트나 이미지를 본문에 끼워넣는 게 안 됨 (링크만 됨).
→ 노트끼리 엮는 핵심 기능이 빠짐.

**C-3. 수식** `$E=mc^2$`
수학 수식이 예쁘게 렌더 안 되고 원문 그대로 보임.
→ 학술·기술 노트에서 아쉬움. (KaTeX 등)

**C-4. 하이라이트** `==형광펜==`
`==`로 감싼 형광펜 표시가 마크다운으론 안 먹음.
→ 별도 하이라이트 기능은 있지만 이 문법은 미지원.

**C-5. 태그** `#태그`
본문 속 `#태그`가 특별히 강조 안 됨.
→ 태그로 분류하는 흐름이 약함.

**C-6. 각주** `[^1]`
각주 표기·연결이 렌더 안 됨.
→ 긴 글 쓸 때 부족.

**C-7. 댓글** `%% %%`
화면엔 안 보이고 원문에만 남는 메모 문법 미지원.

## D. 에디터 기본기 🟡

**D-1. 코드블록 색칠 없음**
코드 넣어도 언어별 색이 안 입혀지고 회색 덩어리로만 보임.
→ 코드 가독성 떨어짐. (CM: `markdown({ codeLanguages })`)

**D-2. 검색(Cmd+F) 없음**
에디터 안에서 단어 찾기/바꾸기가 안 됨.
→ 긴 문서에서 불편. (CM: `@codemirror/search`)

**D-3. 접기(fold) 없음**
헤딩·리스트·코드를 접어서 숨기는 기능 없음.
→ 긴 문서 훑어보기 불편.

**D-4. 괄호 짝 표시 없음**
커서가 `(`에 가도 짝 `)`를 강조 안 함.
→ 사소하지만 편집 보조 부족. (CM: `bracketMatching()`)

## E. 잠재 버그 ⚪

**E-1. 위키링크를 정규식으로 처리**
코드블록 안에 `[[ ]]`를 써도 위키링크로 잘못 인식함.
→ 코드 예시 쓸 때 오작동 소지. (`livePreview.ts:251`)

**E-2. 윈도우 IME 미검증**
`imeListContinue`(조합 후 Enter 수정)가 맥(WKWebView)에서만 검증됨.
→ 윈도우(WebView2=Chromium) 빌드 시 점검 필요.

## 우선순위 한 줄 정리

- **1순위(품질 직결)**: A-1 뷰포트 윈도잉 — 긴 노트 성능. 전면 이주 전 필수.
- **2순위(손맛)**: B-1 자동 닫기 + D-1 코드블록 색칠 + D-2 검색 — "Obsidian 같다" 체감 8할.
- **3순위(기능)**: C-1 콜아웃 · C-2 임베드 · C-3 수식 — 제품 방향 따라 선택.
- **버그성**: A-2 매핑 누락 · E-1 위키링크 정규식 — 작지만 정확성 문제.
