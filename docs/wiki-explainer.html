이 위키, 어떻게 동작하나?

개발자 아닌 사람도 이해할 수 있게. 4가지 흐름 + 페이지 종류 3개.

사용자가 함 AI가 함 시스템이 자동으로 함 결과로 남는 것

1. 큰 그림 — 페이지 3 종류

모든 페이지는 셋 중 하나. 누가 쓰느냐로 구분.

사용자 작성

Daily / Writing 노트

매일매일 생각·메모를 그대로 적는 곳. AI는 읽기만. 사용자만 씀.

AI가 정리

Wiki (wiki:custom-*)

Daniel, Migration 같은 누적 페이지. AI가 daily에서 뽑아 정리. 사용자는 검토만.

시스템 자동

System (system:*)

Conventions / Log / Index 3개. AI 운영을 위한 메타 페이지. 자동 갱신.

시스템 자동

Conventions / Log / Index

· Conventions: AI에게 주는 정리 규칙
· Log: AI 작업 일지
· Index: 모든 wiki 페이지 요약 목록

2. 네 가지 흐름

1메모를 적으면 AI가 위키에 정리
1 사용자
Daily 노트에 글을 적음.
예: “Daniel이 음성 합성 프로젝트 시작”
2 시스템
5분간 타이핑 멈춤 (idle) 감지.
노트가 마지막 정리 이후 수정됐는지 확인 (lastEditedAt > lastIngestedAt).
3 AI (Haiku)
현재 위키 전체 + Index 요약 + Conventions 규칙 + 새 노트를 받아 정리 제안 생성.
“Daniel 페이지에 한 줄 추가” + “Index의 Daniel 요약 갱신” + “Log에 한 줄” — JSON으로 출력.
4 시스템
제안들을 큐에 보관. 자동 적용 안 함.
사용자가 직접 확인할 때까지 대기.
2사용자가 검토하고 받아들임
1 사용자
사이드바에서 Wiki 페이지 (예: Daniel) 클릭.
2 시스템
그 페이지 상단에 “검토할 제안 N건” 박스(banner) 표시.
큐에 있던 제안 중 이 페이지 대상인 것만 카드로.
3 사용자
각 카드의 ✓ (수락) 또는 ✕ (거절) 클릭.
4a 수락 결과
카드 내용이 페이지 끝에 진짜 텍스트로 추가됨. 그 텍스트에 “출처 데이터(언제·어디서 왔는지)”가 보이지 않게 박힘.
사용자가 나중에 어디서 왔는지 hover로 확인 가능.
4b 거절 결과
카드만 사라짐. 페이지는 변경 없음.
3위키 기반 답 받기 (/ask)
1 사용자
채팅에 /ask Daniel이 뭐하고 있더라? 입력.
2 시스템
위키 전체 본문을 AI의 시스템 프롬프트 앞쪽(캐시)에 자동으로 붙임.
3 AI (Sonnet)
위키 페이지를 근거로 답하면서 출처는 [[Daniel]] 같은 형태로 표시.
위키에 없는 내용은 “위키엔 없음” 명시 후 일반 답.
4 시스템
답 화면이 [[Daniel]]을 클릭 가능한 링크로 변환.
5 사용자
링크 클릭 → 그 위키 페이지로 즉시 이동.
4시스템 페이지 자동 갱신 (Index / Log)
1 AI
흐름 1의 마지막 단계에서 위키 정리 제안과 함께 Index 요약 + Log 한 줄도 같이 만듦.
2 시스템
사용자가 Index 페이지 진입하면 → 자동으로 본문 머지. 같은 페이지 요약이 이미 있으면 그 줄 교체, 없으면 추가.
결과: Index는 항상 한 페이지당 한 줄로 정리됨.
3 시스템
사용자가 Log 페이지 진입하면 → 큐의 로그 줄들을 페이지 끝에 자동 append.
4 결과
Index: 위키 카탈로그 / Log: 작업 일지. 사용자가 손 안 대도 항상 최신.

3. 핵심 원리 요약

가장 중요한 원리: AI가 위키에 자동으로 박지 않음. 항상 제안 → 사용자 검토 → 수락 → 적용. 그래서 위키는 사용자가 신뢰할 수 있는 상태로 유지됨.

3계층 분리: 사용자 작성(daily) / AI 정리(wiki) / 시스템 운영(system) 이 명확히 분리. 사이드바도 두 그룹 (System / Wiki) 로 시각 분리.

자동 트리거: 사용자가 글 쓰는 동안엔 AI가 끼어들지 않음. 5분 idle 후 백그라운드로 동작. 사용자 워크플로 방해 최소화.

출처 추적: 위키에 추가된 모든 줄은 “어느 daily의 어느 문장에서 왔는지” 메타데이터 보존. hover로 확인 가능.

cross-link: AI가 위키를 정리하거나 답할 때 다른 페이지 이름이 등장하면 자동으로 [[Title]] 링크로 만듦. 위키가 평면 목록이 아니라 그래프로 자랄 수 있게.
